Run the agent team on a review

Three specialist agents each quote what the review says about one aspect, working in parallel. Python checks every quote against the text and computes the scores, and an arbiter settles quotes claimed by two aspects. A lead agent gives the overall verdict. Each review ends up as a point in 3-D aspect space.

Paste a review, or load a random one from the Yelp sample.

How well do the agents agree with reviewers?

The only ground truth is the star rating, so 1–2★ counts as negative, 3★ as neutral and 4–5★ as positive. The per-aspect correlations show how closely each dimension tracks the rating. All metrics are computed in Python with 95% confidence intervals.
